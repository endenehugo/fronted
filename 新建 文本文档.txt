## 一、 核心设计原则与硬性约束

1. **零后端与零外部资源依赖**：严禁依赖外部音频文件（MP3/WAV）或需要鉴权的后端 API。所有声音通过浏览器原生 **Web Audio API** 实时程序化合成，所有情绪解析与星云渲染均在客户端本地完成，确保打开链接 **3 秒内** 进入可交互状态。
2. **三分钟惊艳闭环**：评委平均停留时间为 1~3 分钟。首屏必须以 **100vw × 100vh 全屏沉浸式 3D 动态星云** 冲击视觉，提供「一键星系预设 + 输入心情生成星云 + 鼠标/键盘拨动星弦 + 定格星云明信片」完整体验。
3. **技术栈规范**：
* 框架：`React 18` + `TypeScript` + `Vite` + `Tailwind CSS`
* 3D 渲染：`Three.js`（自定义 `ShaderMaterial` 粒子系统 + `UnrealBloomPass` 后期辉光）
* 音频引擎：原生 `Web Audio API`（振荡器 + 滤波器 + 延迟混响 + `AnalyserNode` FFT 频谱分析）
* 图标库：`lucide-react`

## 二、 前端视觉规范：沉浸式「星云（Nebula）」系统

### 1. 星云多层结构与 Shader 设计

不要使用普通的随机散点，需构建具有天体物理美感的**螺旋吸积星云**：

* **粒子规模**：桌面端默认 `18,000` 颗粒子（检测到移动端或低帧率时自动降级至 `8,000` 颗，保障 60 FPS）。
* **几何分布（`BufferGeometry`）**：
* **核心恒星区（20%）**：高密度、高亮度中心核，随音频低频产生心跳式呼吸膨胀。
* **对数螺旋旋臂（60%）**：3~4 条主旋臂，基于极坐标半径 $r$ 实现开普勒差速旋转（内圈角速度大于外圈），叠加 3D Simplex/Curl Noise 产生气体湍流褶皱。
* **外围星尘晕（20%）**：大尺寸低透明度弥散粒子，营造深空星云云雾体积感。


* **材质与混合**：
* 使用程序化生成的径向高斯渐变纹理作为粒子贴图，消除方形锯齿。
* 开启 `THREE.AdditiveBlending`（叠加混合）与 `depthWrite: false`，搭配 `EffectComposer` + `UnrealBloomPass` 实现星云核心过曝泛光效果。



### 2. 多模态交互与视听共振（Audio-Reactive）

* **FFT 频谱实时驱动**：每帧从 `AnalyserNode` 读取低频（Bass, 20–150Hz）、中频（Mid, 150–2000Hz）、高频（Treble, 2000Hz+）能量值并传入 Shader Uniforms：
* `uBass`：驱动星云核心脉冲半径与 `Bloom` 泛光强度。
* `uMid`：控制旋臂湍流波动幅度（`uTurbulence`）。
* `uTreble`：触发外围星尘高频闪烁（Twinkle）。


* **指针物理场交互**：
* **鼠标移动/悬停**：在 3D 空间投影处生成局部引力旋涡，带动周围粒子偏转并触发轻微高频泛音。
* **鼠标长按（蓄力坍缩）**：粒子向中心黑洞引力坍缩，音调平滑上扬（Pitch Bend）；**松开鼠标瞬间**触发「超新星爆发（Supernova Shockwave）」，粒子波纹向外扩散并奏响饱满和弦。
* **键盘演奏模式**：按下键盘 `A S D F G H J K L` 键时，随机点亮星云中对应区域的一簇亮星（发射光脉冲），同时演奏当前调式音阶的清脆风铃音。

## 三、 声音引擎规范：程序化星际合成器

封装独立的 `NebulaAudioEngine` 单例类，必须包含以下四层声音架构，且通过锁定调式音阶确保**用户任意操作都和谐悦耳**：

1. **Ambient Drone（深空环境铺底）**：2 个微失谐（Detuned ±6 cents）的 Sine/Triangle 振荡器，经过动态低通滤波器（`BiquadFilterNode`）与极慢速 LFO 调制，形成持续包裹感。
2. **Generative Chimes（自动星辰旋律）**：基于当前情绪预设的 BPM 与音阶数组（如五声音阶、利底亚调式），按马尔可夫概率随机生成错落有致的泛音颗粒，接入立体声反馈延迟（`DelayNode`）模拟宇宙空旷混响。
3. **Interactive Synth（交互即时响应音效）**：响应鼠标点击、超新星爆发与键盘 `A-L` 拨弦，使用快速起音（Attack 15ms）、长释音（Release 1.8s）的钟琴音色。
4. **Solar Wind（宇宙背景噪波）**：内存生成粉红噪波（Pink Noise）Buffer，经带通滤波器随星云旋转速度微调风声强弱。

> **浏览器自动播放合规处理**：首屏中央展示极简半透明启动按钮（如 `点击唤醒星云 / IGNITE NEBULA`），在用户首次点击事件中执行 `audioContext.resume()` 并同步触发星云从奇点展开的开场动画。

### 2. 自然语言心情解析器（纯前端零延迟）

* 用户在底部输入框输入任意中文/英文短句（如：“凌晨两点改完代码，既疲惫又觉得一切都值得”）。
* 本地构建**情感维度词典（Valence 效价、Arousal 唤醒度、Mystery 神秘感）+ 否定词/程度副词权重计算器**，将文本映射为连续参数向量，平滑插值（Lerp, 1.5s 过渡）星云的颜色梯度、旋臂螺旋角、粒子速度与合成器调式，同时生成一句定制化的「星云观测日志」浮现于画面上方。

## 五、 核心闭环：「星云声波明信片」与 URL 状态分享

1. **高清明信片导出**：
* WebGL Renderer 必须开启 `preserveDrawingBuffer: true`。
* 点击「定格此刻星云」时，截取当前 Canvas 画面，通过离屏 2D Canvas 合成**玻璃拟态收藏卡片**（包含：星云高清图、用户输入的心情短句、当前星系名称与音阶、实时频谱波形条、生成时间戳），支持一键下载 PNG 图片。


2. **无后端 URL 分享还原**：
* 将当前状态对象 `{ presetId, customText, colors, turbulence, speed, seed }` JSON 序列化后进行 Base64/LZ 压缩写入 `window.location.hash`（如 `#nebula=eyJ...`）。
* 页面初始化时自动检测 URL Hash，若存在则直接还原出完全一致的星云形态与声音氛围，方便评委与好友直接打开分享链接体验。
